# Project memory — muse

## GLOBAL RULE — never use placeholders or fake content
ALWAYS, in EVERY project:
- Never seed, inject, or display placeholder/fake/demo content (fake posts,
  lorem ipsum, dummy accounts, sample data, demo items, mock rows).
- Apps must start BLANK: show only what the user actually created.
- Empty states are required and must be honest and thoughtful.
- Never add fake info back when fixing or redesigning.
- If a demo dataset exists for testing, it must be opt-in (hidden behind a
  "load sample data" button), never shown by default.
